# Contributing a Logo

Anyone with a GitHub account can add a logo. You don't need to know git.

## Submit

1. Open **[Submit a Logo](../../issues/new?template=submit-logo.yml)**.
2. Fill in the brand, game, category and logo type, and drag your file into **Logo File**.
3. Within a couple of minutes, **gtb-bot** checks the file and comments with a preview, or with anything that needs fixing. Edit the issue to fix problems; it re-checks automatically.
4. A maintainer reviews it. Once approved, it's published and you're credited on the site with your GitHub account.

## File Requirements

| | |
|---|---|
| Format | **SVG** (preferred) or **PNG**. If GitHub won't attach an SVG, put it in a .zip |
| PNG size | At least 1024px on the longest side, transparent background |
| SVG | Paths only: convert text to outlines, no embedded bitmaps, scripts or external links. Under 2 MB |
| Extras | Optional animated GIF, MP4 or EPS, up to 20 MB each |

We generate PNGs, a JPG and a ZIP from your file, so you only need to upload one.

## Rules

- **Your own work.** Recreate the logo yourself; don't upload rips or other people's files.
- **No AI.** No part of the logo can be AI-generated. Submissions that look generated are declined.
- **One logo per submission.** Submit each logo type (icon, wordmark, lockup…) separately.
- **Brand already has this type of logo?** Submit yours anyway. Every submission is its own logo ("Icon 2"), or give it a **Logo Name** like "Alternate".

## Update Your Logo

Want to add an SVG, or replace your logo with a better version? Open **[Update a Logo](../../issues/new?template=update-logo.yml)** and paste the logo's page link. It's checked like a new submission, and the bot shows your current and new versions side by side. You can only update logos you're credited for.

## Requests

Want a logo that isn't here? **[Request it](../../issues/new?template=request-logo.yml)**, or 👍 an existing request.

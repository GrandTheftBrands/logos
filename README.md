# Grand Theft Brands — Logos

Community-made recreations of brand logos from the Grand Theft Auto series, free to download at Grand Theft Brands.

- **Add a logo:** [Submit a Logo](../../issues/new?template=submit-logo.yml) — no git needed. See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Improve your own logo:** [Update a Logo](../../issues/new?template=update-logo.yml), for example to add an SVG.
- **Want one that's missing?** [Request a Logo](../../issues/new?template=request-logo.yml).
- **How files are organised:** [CONTENT.md](CONTENT.md).

Grand Theft Brands is not affiliated with or endorsed by Rockstar North, Take-Two Interactive, any of the depicted brands, artists, personalities, or related shareholders.

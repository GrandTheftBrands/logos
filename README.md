# Grand Theft Brands — Logos

Community-made recreations of brand logos from the Grand Theft Auto series, free to download at Grand Theft Brands.

> Submissions open at launch. You'll submit through a GitHub Issue form — no git knowledge needed — and your GitHub account is credited on the site.

Grand Theft Brands is not affiliated with or endorsed by Rockstar North, Take-Two Interactive, any of the depicted brands, artists, personalities, or related shareholders.
